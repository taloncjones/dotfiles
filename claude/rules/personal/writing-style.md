# Writing Style

Pick the style by the kind of text. The Response Style rules still apply.

- Prose (chat replies, Slack, PR narrative, Jira comments, email): follow
  Orwell's six rules from "Politics and the English Language" (1946).
- Technical and reference text (status tables, docs, READMEs, runbooks,
  docstrings, PR test plans, Confluence pages): follow the Google developer
  documentation style guide, https://developers.google.com/style. Present
  tense, parallel bullets with one idea each, a `Topic: outcome` lead per
  bullet, specific nouns over pronouns, no idioms, consistent numbers.
- Mixed text such as a PR body: prose for the narrative, technical style
  for the test plan and lists.
- Unsure: a reader scanning for a fact gets technical style; a reader
  following an argument gets prose.
